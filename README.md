# PostaFácil Studio

Plataforma em desenvolvimento para planejar, criar e gerenciar conteúdo de marketing com inteligência artificial.

## Objetivos
- Organizar conteúdos para diferentes empresas.
- Planejar Reels e publicações.
- Permitir aprovação manual ou publicação automática.
- Integrar serviços de IA e redes sociais por APIs oficiais.

## Etapas do projeto
1. Organizar o protótipo.
2. Preparar a interface web.
3. Implementar login seguro e separação de clientes.
4. Criar banco de dados e armazenamento.
5. Integrar provedores de IA.
6. Implementar integrações oficiais com redes sociais.

## Situação atual
O protótipo inicial funciona localmente no navegador. As integrações, o login real e a publicação automática ainda precisam ser desenvolvidos.

## Segurança
Não colocar senhas, tokens ou chaves de API nos arquivos do projeto.
